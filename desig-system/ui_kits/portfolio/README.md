# UI kit — Portfolio (one page)

Recreation of the single frame the source file defines: `portafolio` (Figma node `1:91`), a 1440 × 6453 one-page portfolio on the navy canvas.

## Files
- `index.html` — assembles the whole page; the EN/ES pills are live and swap the bio copy.
- `Hero.jsx` — green scribble band, name, role, language pills, bio paragraph.
- `DisplayHeading.jsx` — the 200px Bebas section heading (PROJECTS / EXPERIENCE).
- `ProjectRow.jsx` — project label + two 589×379 shots (on a white 28px card, or bare on navy) + two copy columns.
- `Community.jsx` — 180px orange two-line heading, orange bleed block, talks/recognition list.
- `Contact.jsx` — rotated "contact me" heading + the three profile links.
- `Footer.jsx` — white Chimborazo line drawing and the 6,263.47 m stat.

## Deliberate omissions
The source frame carries placeholder Lorem Ipsum in every project and experience paragraph, and the same single bitmap in all four image slots. Both are reproduced as-is rather than invented around. The English bio is a translation of the Spanish original — the file only contains the Spanish copy.
